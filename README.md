# ucopy releases

Downloads of **ucopy**, a file-recovery copier and backup tool: it copies what can be read off
failing drives and maps what can't, keeps scheduled backups, and backs up Android phones to your
choice of USB drive, a network shared folder or through your desktop ucopy app.

- **Windows:** `ucopy-setup.exe` from the [latest release](../../releases/latest).
- **Android:** `ucopy-<version>.apk` from the same release.
- **macOS:** `ucopy-<version>.dmg` from the same release.

Installed copies look here for updates (`updates.json`) and offer them; nothing is installed
without your tap. Windows downloads are signed by ucopy and checked before they run; Android
accepts only updates signed with the app's own key.
